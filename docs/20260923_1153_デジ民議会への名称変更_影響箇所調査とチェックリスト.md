- 作成日: 2026-09-23
- 最終更新: 2026-09-23（PR #13・#14 のマージと、T3「リブランドの残り」（`feat/rebrand-remaining`）の反映）
- 対象ブランチ: `develop`（調査時点はコミット `3975ccfc`）
- 目的: サービス名「みらい議会（札幌市版）」を「**デジ民議会**」に変更するにあたり、旧名称が残っている箇所を洗い出して、変更要否と作業チェックリストを整理する。

## 1. 前提と論点（先に決めること）

実装前に次の点を決める。決まらないと文言・ファイル名・URL が確定しない。

| # | 論点 | 選択肢の例 | 現状 |
|---|------|-----------|------|
| D1 | **正式表記**（サイト名 `siteName`） | `デジ民議会` / `デジ民議会＠札幌市` / `デジ民議会 札幌市版` | web は `みらい議会＠札幌市`、admin・keywords・README は `みらい議会ー札幌市版` で**表記が割れている** |
| D2 | **短縮名**（PWA の `short_name`） | `デジ民議会` など、ホーム画面で切れない長さ | `みらい議会＠札幌市` |

### 決定事項（2026-09-23）

| # | 決定 |
|---|------|
| D1 | 正式表記は **`デジ民議会`**（「＠札幌市」「札幌市版」などは付けない）。web・admin・keywords・README をこの表記にそろえる |
| D2 | 短縮名も **`デジ民議会`**（D1 と同じ） |
| D3 | ハッシュタグは **`#デジ民議会`** |
| D4 | 英字スラッグは **`dejimin-gikai`**（ヘボン式。当初 `dezimin-gikai` としたが変更） |
| D5 | **(b)**：表示名に加えて、リポジトリ名とパッケージ名（`@mirai-gikai/*` → `@dejimin-gikai/*`）も変える。CSS トークンと DB（§3.8）は変えない |
| D6 | ロゴ・OGP・アイコンのうち「みらい」に関係する部分は、すべて「デジ民」にする（例: `logo.svg` と `ogp.svg` の「みらい議会」→「デジ民議会」、favicon・iOS アイコンの「み」→「デ」） |
| D7 | §1「D7 について」の方針案のまま進める（派生元の表記は残す） |

### D7 について（注意）

本リポジトリは **AGPL-3.0**（`LICENSE`）で、チームみらいの「みらい議会」を基にしている。サービス名を変えても、**元の成果物からの派生であることの表記と著作権表示は残す**必要がある。したがって「チームみらい」「みらい議会」という語は**全部消すのではなく**、次のように仕分ける。

- **残す**: 派生元の説明（about の「ベースに作成しています」、FAQ の「公式サービスではありません」、footer の「運営しているものではありません」、`LICENSE`、`CLA.md`）
- **変える**: 自サービスの名前として「みらい議会」を名乗っている箇所
- **消す／見直す**: 自サービスがチームみらいの活動の一部であるかのような文言（「チームみらいから連絡する」など）

### D5 の推奨

**(b) までを段階的に行い、(c) はやらない**ことを推奨する。

- `mirai-text` などの CSS カラートークン（約 400 箇所）と、DB テーブル `mirai_stances`・型 `MiraiStance` は、利用者の目に触れない。変えると差分が大きく、上流（福岡市版・本家）からの取り込みもしにくくなる。
- パッケージスコープ `@mirai-gikai/*` とリポジトリ名は外から見えるが、変えるとインポート文やスクリプトが広く変わるため、表示名の変更とは**別の PR** に分ける。

## 2. 調査方法

```bash
git grep -n -I -E "みらい議会|チームみらい|札幌版|Team Mirai|mirai" \
  -- ':!docs/schema' ':!pnpm-lock.yaml'
```

- ヒットは約 230 ファイル。そのうち大半は CSS トークン（`text-mirai-text` など）と `@mirai-gikai/*` の import。
- 次のものは**名称変更とは無関係**なので対象外とした。
  - `mirai-sapporo`（会派「未来さっぽろ」のスラッグ。`.claude/skills/update-bills/SKILL.md` など）
  - `tmp_council_page.html` 内の「みらい川崎市議会議員団」（川崎市の会派名。ファイル自体が不要な一時ファイル）
  - `web/public/icons/about-typography.svg`（中身は英字 “About” のパス。名称は含まない）
- DB に入っているデータや、Langfuse のプロンプトなど**リポジトリの外にある箇所**は `git grep` では見つからないため、§3.6 に「要確認」としてまとめた。
