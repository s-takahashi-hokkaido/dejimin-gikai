## 2. デジ民議会

### 2-1. 「デジ民®」（株式会社ドリーム・アーツ）— 衝突の可能性あり

- ドリーム・アーツ（大企業向け業務デジタル化 SaaS「SmartDB」等の提供元）は、
  [サイトのご利用規約](https://www.dreamarts.co.jp/terms-of-use/) の「商標」の節で、
  自社の登録商標として **「デジタルの民主化®」「デジ民®」** を列挙している
  （同じ列に DreamArts®、SmartDB®、INSUITE® など。2026-09-23 に確認）
- 同社は「デジタルの民主化」をコーポレートスローガンにしており、
  [デジタルの民主化DAY（通称：デジ民DAY）](https://hibiki.dreamarts.co.jp/smartdb/democratization-day/) というイベントを継続開催している（第19回が 2026-08-25）
- 同社の「デジ民」は「デジタルの**民主化**」の略で、こちらの「デジタル**民主主義**」とは元の語が違う。
  ただし略した結果の文字列「デジ民」は同じ
- **分かっていないこと**: 登録番号、区分、指定商品・役務、権利者名義、存続期間。
  → これが分からないと、デジ民議会（Web サービス＝主に第42類・第41類・第35類あたり）と重なるか判断できない。
  同社の事業が SaaS なので、第9類・第42類を含んでいる可能性は十分にある（推測。未確認）

**なぜ「デジ民議会」でも関係しうるか（事実として書ける範囲）**:
商標の類否は一般に、外観・称呼（読み）・観念を総合して判断されるとされる。
「議会」はこのサービスの内容をそのまま表す語なので、名前のうち「デジ民」の部分が目立つ部分として扱われる可能性がある。
**実際に類似と判断されるかどうかは専門家の判断事項**であり、ここでは結論を出さない。

### 2-2. 「デジ民投票」（デジモン公式サイト）— 参考

- バンダイのデジモン公式総合サイトに、ファン投票企画
  [デジ民投票](https://digimon.net/fun/) がある（第158回まで継続中）。® や ™ の表示はない
- 「デジモン」＋「国民投票」のもじりで、政治・議会の文脈ではない。
  名前の衝突としての懸念は小さいが、**「デジ民」で検索すると上位にこれとドリーム・アーツが出る**
  （＝検索での見つけてもらいやすさの面では不利）

### 2-3. 同名・類似の Web サービス

- 「デジ民議会」という名前の先行サービスは見つからなかった（検索で出るのは本リポジトリの PR のみ）
- 近い領域の先行プロジェクト: [デジタル民主主義2030](https://dd2030.org/)（安野貴博氏らのオープンソースコミュニティ。「いどばた」「Polimoney」等）、
  チームみらいのマニフェストの[「デジタル民主主義」](https://policy.team-mir.ai/policies/digital-democracy)の章。
  いずれも「デジ民」とは略していない。
  名前の衝突ではないが、方針ドキュメント §4「『デジタル民主主義』という語について」の懸念（チームみらいとの連想）は、
  検索結果の上でも実際に起きていることが確認できた

## 3. EZO CIVIC

- 「EZO CIVIC」「EzoCivic」「エゾシビック」の完全一致では、商標表示・サービス・団体とも見つからなかった
- 「EZO」を含む名前は多数ある（北海道の地域名として一般的なため）。IT に近いものだけ挙げる:
  - [EZO](https://ezo.io/) — 資産管理 SaaS（海外企業）。**ソフトウェアの分野で「EZO」単体の名前を使っている**。日本での商標登録の有無は未確認
  - [EZOHUB](https://x.com/ezohub) — 札幌×東京の共創コミュニティ
  - EZO TECH（鹿製品）、EZO-ISM（自動車のエアロパーツ）、有限会社EZOコーポレーション（苫小牧）など
- 「CIVIC」は本田技研工業の車名として著名な商標だが、分野（自動車）が大きく違い、英語の一般語でもある。
  **自動車部品メーカー EZO-ISM が Honda Civic 用パーツを売っているため、英語で「EZO Civic」と検索すると車の部品が上位に出る**（検索上の不利）
- GitHub: `ezocivic` / `ezo-civic` のユーザー・Organization は存在しない（取得可能）

## 5. ユーザーにお願いしたいこと

### 5-1. J-PlatPat で「デジ民」の登録内容を確認する（最優先・10分程度）

ブラウザで [J-PlatPat 商標検索](https://www.j-platpat.inpit.go.jp/t0100) を開き、次を検索する。

1. **称呼（読み）で検索**: 検索項目「称呼（単純文字列検索）」に `デジミン`
   - ヒットしたものについて、**登録番号・権利者・区分・指定商品・役務・存続状態（生きているか）** を控える
   - ドリーム・アーツ名義のものが出るはず。**区分に第9類・第35類・第41類・第42類が含まれるか**を特に見る
2. 同じく称呼で `デジミンギカイ`、`エゾシビック`、`イーゼットオーシビック`、`エゾ`（件数が多ければ区分で絞る）
3. 区分での絞り込み: 第9類（ソフトウェア）、第35類（広告・事業の管理）、第38類（電気通信）、
   第41類（教育・情報提供）、第42類（SaaS・プログラムの提供）、第45類（タスク分割ドキュメントの指定どおり。該当しそうな役務があるかは相談時に確認する）
4. 結果はこの文書に追記する（§6 の表に行を足す）

### 5-2. 名前をどうするか決める

5-1 の結果によって選択肢が変わる。

| 5-1 の結果 | 選択肢 |
|---|---|
| 「デジ民」の区分がこちらの役務と重ならない | このまま使う（念のため 5-4 の無料相談で確認してもよい） |
| 重なる、または重なるか判断がつかない | (a) 弁理士に相談してから決める（5-4）<br>(b) 早めに名前を変える（表示名・パッケージ名・リポジトリ名を変えた直後なので、**公開前の今が一番安い**）<br>(c) 権利者に使用の了承を求める |

判断材料として: **公開前なら名前の変更は PR 数本で済む**（PR #13・#14 の範囲）。
公開して議員に声を掛けた後の変更は、名乗り・ドメイン・議員への説明のやり直しになる。
