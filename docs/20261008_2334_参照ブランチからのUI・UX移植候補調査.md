## B. 中規模の UX 改善（札幌版にも合う）

### B1. 文字を大きくする切り替え（福岡 2026-05-29）

**状況: ✅ 移植済み（作業ブランチ）。** `web/src/lib/text-size/` を追加し、ハンバーガーメニューと PC メニュー（ルビ切り替えの下）に置いた。福岡市版は `text-xs/sm/base` だけを拡大していたが、北海道版は `text-[12px]`〜`text-[15px]` の任意値も本文に多いので対象に含めた。`index.ts` はリポジトリの方針に合わせて作らず、各ファイルから直接 import する

- ハンバーガーメニューと PC メニューに「文字を大きくする」スイッチ。選択は保存して次回も反映する
- 実装: `web/src/lib/text-size/`（toggle・initializer・hook）、`components/header/hamburger-menu.tsx`、`components/layouts/desktop-menu/`
- 北海道版には既にふりがな（rubyful）があり、同じ「読みやすさ」系の設定として並べられる。DB 変更なし
- 規模: 小〜中

### B2. 議案に「提出日」「議決日」を持たせる（福岡 #113）

**状況: 🔧 作業ブランチで対応。** 方針は福岡市版に寄せる（`submitted_date` / `decided_date` を追加し、`published_at` はサイトの公開日時として残す）。国政版の `published_at`→`submitted_at` リネームは admin の並び替え・監査ログ・統合機能まで波及するため採らない。北海道版の seed は `published_at` に本会議提出日を入れているので、表示は `submitted_date` が無ければ `published_at` にフォールバックする

- `bills` に提出年月日・議決年月日カラムを追加し、議案カード・議案詳細ヘッダーに表示。管理画面のフォームにも入力欄を追加
- 北海道版の `bills` には `published_at`（サイト公開日）しかなく、議会での日付を出せない。札幌市議会の議案一覧には提出日・議決日があるので、`update-bills` スキルの手順にも追記が必要
- 参考: 国政版は #762 で `published_at` を `submitted_at` にリネームしている。どちらに寄せるか決めてから着手する
- 規模: 中（マイグレーション・型再生成・admin フォーム・`bill-dates.ts` 純粋関数とテスト）

### B3. 記者会見の配付資料 PDF リンク（福岡 #104）

**状況: ✅ 移植済み（作業ブランチ）。** `press_conference_items.material_url` を追加（マイグレーション `20261009000000_add_material_url_to_press_conference_items.sql`）し、発表カードに「配付資料（PDF）」リンクを出す。`update-press-conferences` スキルに入れ方を追記した

- 発表項目ごとに市の配付資料 PDF へのリンクを出す（`press_conference_items.material_url` 追加）
- 札幌市も市長定例記者会見の資料を PDF で公開しているので、そのまま使える。`update-press-conferences` スキルの手順にも反映する
- 規模: 小（マイグレーション 1 本＋表示）

### B4. 一般質問の 3 行サマリー＋テーマ別アコーディオン（福岡 #87・#88・#89）

**状況: 🔧 作業ブランチで画面とテーブルまで対応。** サマリー本文（AI 生成）の作成・登録は `update-general-questions` スキルの手順で、ユーザーの確認を取ってから行う

- 定例会の一般質問ページの冒頭に「どんな話があった？」3 行サマリー、テーマごとに折りたためる一覧、テーマを畳んだ状態でもテーマ別 3 行を表示、カードから該当テーマの位置へジャンプ
- `general_question_overviews` テーブル（セッション単位の `lines` とテーマ別 `theme_lines`）を追加。**サマリー本文は AI 生成**なので、CLAUDE.md の「AI 生成コンテンツの DB 更新ルール」に沿った確認手順を `update-general-questions` スキルに足す
- 北海道版の `session-topics-view.tsx` は福岡 #87 以前の形のまま
- 規模: 中

### B5. トップのバナーをアコーディオンにまとめる（福岡 #83）

**状況: ➖ 見送り。** 北海道版のトップで畳む候補になるのは予算バナー 1 つだけ（記者会見のお知らせは最新情報なので畳まない、一般質問バナーは福岡市版でも単独）で、アコーディオンにする効果が無い。バナーが増えたときに改めて検討する。

かわりに、同じ並びの**予算バナーが開会中の会期にリンクしていて、予算を審議しない定例会の間は中身の無いページに飛ぶ**不具合（福岡 #74 で直されたもの）を作業ブランチで直した。あわせてバナーと部局詳細の「令和8年度」の固定表記を、会期名から年度を出すようにした

- `BannerAccordion`（Collapsible）で関連バナーを 1 つに畳み、トップの縦の長さを抑える
- 北海道版のトップは記者会見のお知らせ・予算概要・一般質問の 3 バナーが縦に並ぶ。今後バナーが増えるならまとめたい
- 福岡市版は同じ時期に「税金の使い道マップ（外部サイト）」へのリンクも追加している（#76）。札幌市のページがあるかは**未確認**
- 規模: 小

### B6. 議案記事の「レビューステータス」表示（国政 #735・#739・#745・#750）

**状況: 🔧 作業ブランチで対応。** 国政版の文言は「複数有識者によるレビュー」だが、北海道版の運用（AI が作った解説を人が確認して載せる）に合わせて言い換える

- 議案記事が人の確認を通ったかをバナーとバッジ（トップのカードにも）で示す
- 北海道版の解説（`bill_contents`）は AI 生成を人が確認して載せる運用なので、「確認済み」を見せられると信頼性の説明になる
- 規模: 中（マイグレーション・admin の切り替え・表示）

## E. 移植しないもの

| 内容 | 理由 |
| --- | --- |
| チームみらいの賛否・判断理由・予約公開（国政 #996・#998 ほか） | 政党固有の機能。北海道版は会派見解（`faction_stances`）で別に持っている |
| チームみらい紹介セクション・SNS リンク・自主制作ガイドラインへのフッター導線（国政 #913・#989） | 本家の運営向け |
| オープンデータ API・開発者ページ・MCP サーバー | UI・UX の範囲外。必要になったら別途検討 |
| 福岡市財政ページ `/finance` | 福岡市版でも廃止済み（#84） |
| 福岡市固有のデータ追加（候補者情報・議事録データなど） | データのみの変更 |

なお国政 #987（fork 版は自身のソースコードへのリンクを掲示する）は、北海道版のフッター（`footer.config.ts:46`）に自リポジトリへのリンクが既にあるため対応済み。ただしリポジトリを公開状態にしておく必要がある。
